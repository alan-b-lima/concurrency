Aulas

O curso é dividido em 5 módulos que possuem certa interdependência. O zerézimo módulo é de introdução ao curso; o primeiro módulo é dedicado a uma breve revisão de conceitos de sistemas operacionais, para então introduzir multithreading no segundo módulo; o terceiro módulo introduz o modelo de atores; o quarto módulo é apresenta a programação orientada a eventos; por fim, o quinto e último módulo é dedicado à comunicação de processos sequenciais.

Os slides das aulas são dispostos abaixo:

  1. 0. Introdução à Programação Concorrente
  2. 1. Conceitos de Sistemas Operacionais
  3. 2. Multithreading
  4. 3. Modelo de Atores
  5. 4. Programação Orientada a Eventos
  6. 5. Comunicação de Processos Sequenciais
